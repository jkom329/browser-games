# Browser Games

Five small single-file browser games, built with Muse. Each game is one self-contained `index.html` — open it in a browser and play, no build step.

- **Space Combat** (`space-combat/`) — 2D Asteroids-style space combat.
- **Pong** (`pong/`) — Pong with moving, rotating paddles.
- **Nim** (`nim/`) — the classic take-away game against the computer.
- **Marine Tactics** (`marine-tactics/`) — simplified StarCraft-like tactics: 10 marines a side, no base-building, pure positioning against the AI. Mouse only: left-click/drag to select, right-click to move or attack.
- **Top-Down Racer** (`top-down-racer/`) — a TI-83+ style scrolling-track racer: steer to stay on the track and survive as long as you can.
